# 🛠️ Deep Learning Tools & Frameworks

## 📌 Overview

Deep Learning models require specialized frameworks to build, train, and deploy Neural Networks efficiently.

Two of the most widely used tools in Deep Learning are:

- TensorFlow
- Keras

TensorFlow provides the computational power behind Deep Learning models, while Keras provides a simple and user-friendly interface for building those models.

---

# 🚀 TensorFlow

## 🎯 What is TensorFlow?

TensorFlow is an open-source Deep Learning framework used to build, train, and deploy Neural Networks.

It helps developers create Deep Learning models without manually implementing complex mathematical operations.

---

## 🤔 Why Do We Need TensorFlow?

Without TensorFlow, developers would need to manually implement:

- Matrix Multiplication
- Forward Propagation
- Backpropagation
- Gradient Descent
- Weight Updates

for every Neural Network.

TensorFlow automates these processes and makes Deep Learning practical.

---

## 📦 TensorFlow Name

TensorFlow is made up of two words:

### Tensor

Represents data such as:

```text
Vector

Matrix

Higher-Dimensional Data
```

### Flow

Represents the movement of data through a Neural Network.

---

## 🌍 Applications of TensorFlow

TensorFlow is widely used in:

- Artificial Neural Networks (ANN)
- Computer Vision
- Natural Language Processing
- Chatbots
- Image Classification
- Generative AI

---

## ✅ Key Points

- TensorFlow is a Deep Learning framework.
- It handles complex mathematical operations automatically.
- It supports Neural Network training.
- It supports GPU acceleration.
- It is one of the most popular Deep Learning frameworks.

---

# 🚀 Keras

## 🎯 What is Keras?

Keras is a high-level API used to build Neural Networks in a simple and readable way.

It is built on top of TensorFlow and makes Deep Learning development easier.

---

## 🤔 Why Do We Need Keras?

TensorFlow is powerful, but using low-level TensorFlow code can be complex.

Keras simplifies this process by providing easy-to-use functions and structures.

---

## 🚗 TensorFlow vs Keras

### TensorFlow

```text
Engine
```

Provides:

- Computation
- Training
- Performance
- GPU Support

---

### Keras

```text
Driver
```

Provides:

- Simplicity
- Easy Model Creation
- Beginner-Friendly Syntax

---

## 🌍 Applications of Keras

Keras can be used to build:

- ANN Models
- CNN Models
- RNN Models
- NLP Systems
- Computer Vision Applications

---

## ✅ Key Points

- Keras is a high-level API.
- Keras runs on top of TensorFlow.
- Keras reduces the amount of code required.
- Keras makes Deep Learning easier for beginners.
- Most Deep Learning projects use TensorFlow and Keras together.
